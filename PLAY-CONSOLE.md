# Preenchimento do Play Console — ZyPong

URLs previstas após o deploy do commit no Render:

- Política de privacidade: https://zypong.onrender.com/privacy.html
- Suporte e instruções de acesso: https://zypong.onrender.com/support.html
- Jogo: https://zypong.onrender.com/

Essas páginas não substituem os formulários do Console. As informações abaixo descrevem o código web deste repositório. O AAB gerado externamente não foi inspecionado: confira suas permissões, dependências e eventuais SDKs antes de declarar dados ou recursos. Verifique também o tratamento de dados de infraestrutura da hospedagem segundo as definições atuais da seção Segurança dos dados do Google Play.

| Item | Orientação para esta versão web |
| --- | --- |
| Política de privacidade | Informe a URL de privacy.html. Ela usa o canal público de issues do GitHub como contato; um e-mail de suporte deve ser informado separadamente nos detalhes da loja quando solicitado. |
| Detalhes do login / Acesso ao app | Selecione que todas as funcionalidades estão disponíveis sem restrições de acesso. Não há login. Instrução: “Abra o aplicativo e toque em Jogar agora. Nenhuma conta, senha, assinatura ou código é necessário.” |
| Anúncios | O jogo web não contém anúncios. Se o pacote Android também não contiver SDKs de anúncios, responda que não contém anúncios. |
| Classificação de conteúdo | Preencha o questionário como jogo de esporte/arcade com raquetes e bola. Não há violência, sangue, sexo, drogas, apostas, chat ou conteúdo gerado por usuários dentro do jogo. A classificação é calculada pelo questionário; não é definida por esta página. |
| Público-alvo | Escolha as faixas de idade que você realmente pretende atender. Uma aparência simples não determina automaticamente direcionamento a crianças; incluir crianças pode trazer requisitos adicionais. Essa decisão cabe ao responsável pelo app. |
| Segurança dos dados | Vitórias e som ficam no dispositivo. O código web não tem analytics, publicidade, cadastro ou upload de pontuações. Avalie o AAB e os provedores envolvidos antes de responder se há coleta/compartilhamento, conforme as definições do formulário. Não declare “nenhum dado” com base apenas na ausência de login. Não há contas no jogo. |
| Apps governamentais | O projeto atual não é um app governamental. Responda “não” se o responsável não o publica em nome de uma entidade governamental. |
| Recursos financeiros | Não há recursos financeiros, transferências, empréstimos, investimentos ou pagamentos no código web. Escolha a opção de ausência desses recursos, se o AAB também não os adicionar. |
| Saúde | O jogo não oferece funcionalidades de saúde ou medicina e não usa dados de saúde. Escolha a opção correspondente no formulário. |

Antes de enviar: abra as URLs em uma janela anônima e confirme que estão acessíveis sem login, revise o contato de suporte e confirme que as declarações correspondem à versão efetivamente enviada ao Google Play. Não há garantia de aprovação automática.
