Suporte do ZyPong

Como jogar

Toque em Jogar agora. Gire o celular para o modo paisagem. Arraste para cima e para baixo no campo para controlar a raquete azul à esquerda. No computador, use o mouse ou as setas para cima e para baixo com o campo selecionado. O jogo tenta ativar a tela cheia ao iniciar; alguns navegadores exigem rotação manual. Vence quem marcar 7 pontos. Selecione a dificuldade antes de começar.

Acesso sem login

Todas as funcionalidades do jogo web estão disponíveis sem cadastro, senha, assinatura ou código de acesso. Abra o jogo e toque em Jogar agora. Não há compras no jogo.

Modo offline

Acesse o jogo com internet e aguarde o carregamento completo. Depois dessa preparação, o jogo pode funcionar offline. Limpar os dados do site remove os arquivos offline e o histórico local de vitórias.

Problemas e contato

Descreva o problema no canal de suporte no GitHub. Informe o modelo do dispositivo, navegador e os passos para reproduzir. É necessário entrar no GitHub para abrir uma solicitação. As mensagens são públicas: não inclua dados pessoais, senhas ou chaves de assinatura.

Dados locais

Você pode remover vitórias e preferências nas configurações de dados do site do navegador. O jogo não tem contas online. Consulte a Política de Privacidade para detalhes.
